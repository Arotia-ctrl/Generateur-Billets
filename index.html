Police des textes (Montserrat Bold)
Montserrat Bold intégrée

Montserrat Bold est intégrée à la page (fonctionne hors ligne). Un .ttf importé la remplace sur tous les textes. Le nom du candidat est en rouge par défaut : changez la couleur dans l'onglet Éditeur en sélectionnant le cadre du nom.

Règle automatique Candidat (NUM)

Un changement n'affecte que les futurs candidats.

Règle Billet (VOTE)

Chaque candidat peut utiliser la même plage de numéros VOTE (ex. 1 à 50). Le code-barres combine NUM + VOTE pour rester unique.

Éditeur sur votre plaque existante

Placez vos marqueurs dans le 1er billet (en haut à gauche). Utilisez la liste 🎯 Déplacer pour choisir un élément sans risquer de cliquer sur un autre, 🔒 Verrouiller pour figer les éléments en place, et les boutons Manuel (← ↑ ↓ →) ou les flèches clavier pour déplacer avec précision.
